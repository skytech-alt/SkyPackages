# sky-random-bundle

## Установка

**Python:**
```bash
pip install sky-random-bundle
```

**npm:**
```bash
npm install @skypackages/random-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-random-bundle
```

## SkyForge

Генерация безопасных паролей и случайных строк.

```skyforge
пусть lib = подтянуть "skyforge-random-bundle"
```
