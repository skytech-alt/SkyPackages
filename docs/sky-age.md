# sky-age

## Установка

**Python:**
```bash
pip install sky-age
```

**npm:**
```bash
npm install @skypackages/age
```

**SkyForge:**
```bash
SkyForge install skyforge-age
```

## Python API

### `calculate(birth_date, today)`

### Пример использования

```python
from sky_age import calculate

calculate(None, None)
```

## TypeScript / JavaScript API

### `calculate(birthDate, today)`

### Пример использования

```typescript
import { calculate } from "@skypackages/age";

calculate(None, None);
```

## SkyForge

Вычисление возраста по дате рождения.

```skyforge
пусть lib = подтянуть "skyforge-age"
лог(lib.calculate())
```
