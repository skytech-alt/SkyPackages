# sky-email-bundle

## Установка

**Python:**
```bash
pip install sky-email-bundle
```

**npm:**
```bash
npm install @skypackages/email-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-email-bundle
```

## SkyForge
