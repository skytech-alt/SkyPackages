# sky-urltidy-bundle

## Установка

**Python:**
```bash
pip install sky-urltidy-bundle
```

**npm:**
```bash
npm install @skypackages/urltidy-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-urltidy-bundle
```

## SkyForge

Сокращение и восстановление GitHub-ссылок на релизы.

```skyforge
пусть lib = подтянуть "skyforge-urltidy-bundle"
```
