# sky-case-bundle

## Установка

**Python:**
```bash
pip install sky-case-bundle
```

**npm:**
```bash
npm install @skypackages/case-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-case-bundle
```

## SkyForge

Конвертация регистров строк.

```skyforge
пусть lib = подтянуть "skyforge-case-bundle"
```
