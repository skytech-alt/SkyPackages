# sky-coin

## Установка

**Python:**
```bash
pip install sky-coin
```

**npm:**
```bash
npm install @skypackages/coin
```

**SkyForge:**
```bash
SkyForge install skyforge-coin
```

## Python API

### `flip()`

### Пример использования

```python
from sky_coin import flip

flip()
```

## TypeScript / JavaScript API

### `flip()`

### Пример использования

```typescript
import { flip } from "@skypackages/coin";

flip();
```

## SkyForge
