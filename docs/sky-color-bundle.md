# sky-color-bundle

## Установка

**Python:**
```bash
pip install sky-color-bundle
```

**npm:**
```bash
npm install @skypackages/color-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-color-bundle
```

## SkyForge

Работа с цветами: HEX, RGB, контраст.

```skyforge
пусть lib = подтянуть "skyforge-color-bundle"
```
