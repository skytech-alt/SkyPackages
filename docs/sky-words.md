# sky-words

Подсчет слов и оценка времени чтения текста (с поддержкой кириллицы).

## Установка

```bash
pip install sky-words
npm install @skypackages/words
SkyForge install sky-words
```

## API Reference

### Python

#### `def count_words(text)`
Считает количество слов в тексте (кириллица и латиница).

#### `def reading_time(text, wpm)`
Оценивает время чтения (по умолчанию 200 слов в минуту).
