# sky-xml

## Установка

**Python:**
```bash
pip install sky-xml
```

**npm:**
```bash
npm install @skypackages/xml
```

**SkyForge:**
```bash
SkyForge install skyforge-xml
```

## Python API

### `escape(text)`

### `unescape(text)`

### Пример использования

```python
from sky_xml import escape

escape("example")
```

## TypeScript / JavaScript API

### `escape(text)`

### `unescape(text)`

### Пример использования

```typescript
import { escape } from "@skypackages/xml";

escape("example");
```

## SkyForge

Экранирование и разэкранирование XML-сущностей.

```skyforge
пусть lib = подтянуть "skyforge-xml"
лог(lib.escape())
```
