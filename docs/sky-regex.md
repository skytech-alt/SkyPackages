# sky-regex

## Установка

**Python:**
```bash
pip install sky-regex
```

**npm:**
```bash
npm install @skypackages/regex
```

**SkyForge:**
```bash
SkyForge install skyforge-regex
```

## Python API

### `escape(text)`

### Пример использования

```python
from sky_regex import escape

escape("example")
```

## TypeScript / JavaScript API

### `escape(text)`

### Пример использования

```typescript
import { escape } from "@skypackages/regex";

escape("example");
```
