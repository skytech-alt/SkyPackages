# sky-rot13

## Установка

**Python:**
```bash
pip install sky-rot13
```

**npm:**
```bash
npm install @skypackages/rot13
```

**SkyForge:**
```bash
SkyForge install skyforge-rot13
```

## Python API

### `rot13(text)`

### Пример использования

```python
from sky_rot13 import rot13

rot13("example")
```

## TypeScript / JavaScript API

### `rot13(text)`

### Пример использования

```typescript
import { rot13 } from "@skypackages/rot13";

rot13("example");
```
