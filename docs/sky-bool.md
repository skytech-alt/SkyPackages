# sky-bool

## Установка

**Python:**
```bash
pip install sky-bool
```

**npm:**
```bash
npm install @skypackages/bool
```

**SkyForge:**
```bash
SkyForge install skyforge-bool
```

## Python API

### `parse(value)`

### Пример использования

```python
from sky_bool import parse

parse("value")
```

## TypeScript / JavaScript API

### `parse(value)`

### Пример использования

```typescript
import { parse } from "@skypackages/bool";

parse("value");
```

## SkyForge

Парсинг строк в boolean.

```skyforge
пусть lib = подтянуть "skyforge-bool"
лог(lib.parse())
```
