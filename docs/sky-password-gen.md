# sky-password-gen

## Установка

**Python:**
```bash
pip install sky-password-gen
```

**npm:**
```bash
npm install @skypackages/password-gen
```

**SkyForge:**
```bash
SkyForge install skyforge-password-gen
```

## Python API

### `generate(length, use_symbols)`

### Пример использования

```python
from sky_password_gen import generate

generate(None, None)
```

## TypeScript / JavaScript API

### `generate(length, useSymbols)`

### Пример использования

```typescript
import { generate } from "@skypackages/password-gen";

generate(None, None);
```

## SkyForge

Генератор паролей с настройкой символов.

```skyforge
пусть lib = подтянуть "skyforge-password-gen"
лог(lib.generate())
```
