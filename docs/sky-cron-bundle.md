# sky-cron-bundle

## Установка

**Python:**
```bash
pip install sky-cron-bundle
```

**npm:**
```bash
npm install @skypackages/cron-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-cron-bundle
```

## SkyForge

Парсинг cron-выражений.

```skyforge
пусть lib = подтянуть "skyforge-cron-bundle"
```
