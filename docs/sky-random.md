# sky-random

Генерация безопасных паролей, UUID и случайных строк.

## Установка

```bash
pip install sky-random
npm install @skypackages/random
SkyForge install sky-random
```

## API Reference

### Python

#### `def generate_password(length)`
Генерирует надежный пароль.

#### `def generate_uuid()`
Генерирует UUID v4.

#### `def generate_token(length)`
Генерирует hex-токен.
