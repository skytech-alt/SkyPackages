# sky-http-status-bundle

## Установка

**Python:**
```bash
pip install sky-http-status-bundle
```

**npm:**
```bash
npm install @skypackages/http-status-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-http-status-bundle
```
