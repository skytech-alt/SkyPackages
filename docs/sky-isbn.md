# sky-isbn

Валидация ISBN-10 и ISBN-13.

## Установка

```bash
pip install sky-isbn
npm install @skypackages/isbn
SkyForge install sky-isbn
```

## API Reference

### Python

#### `def is_valid_isbn10(isbn)`
*Документация отсутствует.*

#### `def is_valid_isbn13(isbn)`
*Документация отсутствует.*

### TypeScript / JavaScript

#### `isValidIsbn10(isbn)`
*Документация отсутствует.*

#### `isValidIsbn13(isbn)`
*Документация отсутствует.*
