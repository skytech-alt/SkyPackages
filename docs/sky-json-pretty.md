# sky-json-pretty

## Установка

**Python:**
```bash
pip install sky-json-pretty
```

**npm:**
```bash
npm install @skypackages/json-pretty
```

**SkyForge:**
```bash
SkyForge install skyforge-json-pretty
```

## Python API

### `pretty(text, indent)`

### Пример использования

```python
from sky_json_pretty import pretty

pretty("example", None)
```

## TypeScript / JavaScript API

### `pretty(text, indent)`

### Пример использования

```typescript
import { pretty } from "@skypackages/json-pretty";

pretty("example", None);
```

## SkyForge

Красивый вывод JSON с отступами.

```skyforge
пусть lib = подтянуть "skyforge-json-pretty"
лог(lib.pretty())
```
