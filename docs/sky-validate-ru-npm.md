# sky-validate-ru

**Версия:** `0.1.0` | **Экосистема:** `npm`

Валидация российских реквизитов: ИНН, ОГРН, ОГРНИП, СНИЛС, КПП, БИК, расчётные и корреспондентские счета

## Установка

```bash
npm install @skypackages/validate-ru
```
