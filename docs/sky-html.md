# sky-html

Экранирование и разэкранирование HTML-сущностей.

## Установка

```bash
pip install sky-html
npm install @skypackages/html
SkyForge install sky-html
```

## API Reference

### Python

#### `def escape(text)`
Экранирует спецсимволы HTML.

#### `def unescape(text)`
Разэкранирует HTML-сущности.
