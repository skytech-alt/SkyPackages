# sky-hex

## Установка

**Python:**
```bash
pip install sky-hex
```

**npm:**
```bash
npm install @skypackages/hex
```

**SkyForge:**
```bash
SkyForge install skyforge-hex
```

## Python API

### `encode(text)`

### `decode(hex_str)`

### Пример использования

```python
from sky_hex import encode

encode("example")
```

## TypeScript / JavaScript API

### `encode(text)`

### `decode(hexStr)`

### Пример использования

```typescript
import { encode } from "@skypackages/hex";

encode("example");
```

## SkyForge

Кодирование строки в hex и обратно.

```skyforge
пусть lib = подтянуть "skyforge-hex"
лог(lib.encode())
```
