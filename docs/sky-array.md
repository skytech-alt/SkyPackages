# sky-array

Утилиты для массивов: chunk, unique, flatten, group_by, shuffle.

## Установка

```bash
pip install sky-array
npm install @skypackages/array
SkyForge install sky-array
```

## API Reference

### Python

#### `def chunk(items, size)`
Разбивает список на куски по size элементов.

#### `def unique(items)`
Убирает дубликаты, сохраняя порядок.

#### `def flatten(items)`
Выравнивает вложенные списки в один.

#### `def group_by(items, key)`
Группирует элементы по ключу.

#### `def shuffle(items)`
Возвращает перемешанную копию списка.
