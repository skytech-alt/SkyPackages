# sky-gcd

## Установка

**Python:**
```bash
pip install sky-gcd
```

**npm:**
```bash
npm install @skypackages/gcd
```

**SkyForge:**
```bash
SkyForge install skyforge-gcd
```

## Python API

### `gcd(a, b)`

### Пример использования

```python
from sky_gcd import gcd

gcd(None, None)
```

## TypeScript / JavaScript API

### `gcd(a, b)`

### Пример использования

```typescript
import { gcd } from "@skypackages/gcd";

gcd(None, None);
```

## SkyForge

Наибольший общий делитель (алгоритм Евклида).

```skyforge
пусть lib = подтянуть "skyforge-gcd"
лог(lib.gcd())
```
