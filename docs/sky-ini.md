# sky-ini

## Установка

**Python:**
```bash
pip install sky-ini
```

**npm:**
```bash
npm install @skypackages/ini
```

**SkyForge:**
```bash
SkyForge install skyforge-ini
```

## Python API

### `parse(text)`

### Пример использования

```python
from sky_ini import parse

parse("example")
```

## TypeScript / JavaScript API

### `parse(text)`

### Пример использования

```typescript
import { parse } from "@skypackages/ini";

parse("example");
```

## SkyForge

Парсинг INI-файлов.

```skyforge
пусть lib = подтянуть "skyforge-ini"
лог(lib.parse())
```
