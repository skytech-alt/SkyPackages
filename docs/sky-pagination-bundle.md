# sky-pagination-bundle

## Установка

**Python:**
```bash
pip install sky-pagination-bundle
```

**npm:**
```bash
npm install @skypackages/pagination-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-pagination-bundle
```

## SkyForge

Расчет пагинации и генерация диапазонов страниц.

```skyforge
пусть lib = подтянуть "skyforge-pagination-bundle"
```
