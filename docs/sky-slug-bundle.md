# sky-slug-bundle

## Установка

**Python:**
```bash
pip install sky-slug-bundle
```

**npm:**
```bash
npm install @skypackages/slug-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-slug-bundle
```

## SkyForge

Генерация URL-слагов из текста с поддержкой транслитерации (кириллица).

```skyforge
пусть lib = подтянуть "skyforge-slug-bundle"
```
