# sky-crypto-bundle

## Установка

**Python:**
```bash
pip install sky-crypto-bundle
```

**npm:**
```bash
npm install @skypackages/crypto-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-crypto-bundle
```

## SkyForge

Безопасная генерация токенов и хеширование для SkyForge.

```skyforge
пусть lib = подтянуть "skyforge-crypto-bundle"
```
