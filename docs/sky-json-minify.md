# sky-json-minify

## Установка

**Python:**
```bash
pip install sky-json-minify
```

**npm:**
```bash
npm install @skypackages/json-minify
```

**SkyForge:**
```bash
SkyForge install skyforge-json-minify
```

## Python API

### `minify(text)`

### Пример использования

```python
from sky_json_minify import minify

minify("example")
```

## TypeScript / JavaScript API

### `minify(text)`

### Пример использования

```typescript
import { minify } from "@skypackages/json-minify";

minify("example");
```

## SkyForge

Минификация JSON.

```skyforge
пусть lib = подтянуть "skyforge-json-minify"
лог(lib.minify())
```
