# sky-binary

## Установка

**Python:**
```bash
pip install sky-binary
```

**npm:**
```bash
npm install @skypackages/binary
```

**SkyForge:**
```bash
SkyForge install skyforge-binary
```

## Python API

### `to_bin(n)`

### `from_bin(s)`

### Пример использования

```python
from sky_binary import to_bin

to_bin(42)
```

## TypeScript / JavaScript API

### `toBin(n)`

### `fromBin(s)`

### Пример использования

```typescript
import { toBin } from "@skypackages/binary";

toBin(42);
```

## SkyForge

Конвертация в двоичную систему.

```skyforge
пусть lib = подтянуть "skyforge-binary"
лог(lib.to_bin())
```
