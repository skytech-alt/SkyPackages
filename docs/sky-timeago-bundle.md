# sky-timeago-bundle

## Установка

**Python:**
```bash
pip install sky-timeago-bundle
```

**npm:**
```bash
npm install @skypackages/timeago-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-timeago-bundle
```

## SkyForge

Относительное время: '5 минут назад'.

```skyforge
пусть lib = подтянуть "skyforge-timeago-bundle"
```
