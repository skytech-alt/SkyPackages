# sky-uuid-short

## Установка

**Python:**
```bash
pip install sky-uuid-short
```

**npm:**
```bash
npm install @skypackages/uuid-short
```

**SkyForge:**
```bash
SkyForge install skyforge-uuid-short
```

## Python API

### `generate()`

### Пример использования

```python
from sky_uuid_short import generate

generate()
```

## TypeScript / JavaScript API

### `generate()`

### Пример использования

```typescript
import { generate } from "@skypackages/uuid-short";

generate();
```

## SkyForge

Короткий UUID в base62.

```skyforge
пусть lib = подтянуть "skyforge-uuid-short"
лог(lib.generate())
```
