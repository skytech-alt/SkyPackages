# sky-diff-bundle

## Установка

**Python:**
```bash
pip install sky-diff-bundle
```

**npm:**
```bash
npm install @skypackages/diff-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-diff-bundle
```
