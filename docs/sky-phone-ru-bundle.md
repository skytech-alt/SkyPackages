# sky-phone-ru-bundle

## Установка

**Python:**
```bash
pip install sky-phone-ru-bundle
```

**npm:**
```bash
npm install @skypackages/phone-ru-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-phone-ru-bundle
```

## SkyForge

Валидация российских телефонов.

