# sky-netguard-bundle

## Установка

**Python:**
```bash
pip install sky-netguard-bundle
```

**npm:**
```bash
npm install @skypackages/netguard-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-netguard-bundle
```

## SkyForge

Валидация сетевых параметров (IP, CIDR, MAC, порты) для SkyForge.

```skyforge
пусть lib = подтянуть "skyforge-netguard-bundle"
```
