# sky-mask-bundle

## Установка

**Python:**
```bash
pip install sky-mask-bundle
```

**npm:**
```bash
npm install @skypackages/mask-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-mask-bundle
```

## SkyForge

Маскировка чувствительных данных для логов.

```skyforge
пусть lib = подтянуть "skyforge-mask-bundle"
```
