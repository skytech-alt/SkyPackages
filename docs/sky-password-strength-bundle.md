# sky-password-strength-bundle

## Установка

**Python:**
```bash
pip install sky-password-strength-bundle
```

**npm:**
```bash
npm install @skypackages/password-strength-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-password-strength-bundle
```
