# sky-number-bundle

## Установка

**Python:**
```bash
pip install sky-number-bundle
```

**npm:**
```bash
npm install @skypackages/number-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-number-bundle
```

## SkyForge

Компактное форматирование чисел (K, M, B).

```skyforge
пусть lib = подтянуть "skyforge-number-bundle"
```
