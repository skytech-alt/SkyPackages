# sky-roman

## Установка

**Python:**
```bash
pip install sky-roman
```

**npm:**
```bash
npm install @skypackages/roman
```

**SkyForge:**
```bash
SkyForge install skyforge-roman
```

## Python API

### `to_roman(num)`

### `from_roman(roman)`

### Пример использования

```python
from sky_roman import to_roman

to_roman(42)
```

## TypeScript / JavaScript API

### `toRoman(num)`

### `fromRoman(roman)`

### Пример использования

```typescript
import { toRoman } from "@skypackages/roman";

toRoman(42);
```

## SkyForge

Конвертация арабских чисел в римские и обратно.

```skyforge
пусть lib = подтянуть "skyforge-roman"
лог(lib.to_roman())
```
