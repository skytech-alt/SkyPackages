# sky-datetime-ru-bundle

## Установка

**Python:**
```bash
pip install sky-datetime-ru-bundle
```

**npm:**
```bash
npm install @skypackages/datetime-ru-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-datetime-ru-bundle
```

## SkyForge

Производственный календарь РФ: праздники, рабочие дни.

```skyforge
пусть lib = подтянуть "skyforge-datetime-ru-bundle"
```
