# sky-semver-bundle

## Установка

**Python:**
```bash
pip install sky-semver-bundle
```

**npm:**
```bash
npm install @skypackages/semver-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-semver-bundle
```

## SkyForge

Семантическое версионирование: парсинг и сравнение.

```skyforge
пусть lib = подтянуть "skyforge-semver-bundle"
```
