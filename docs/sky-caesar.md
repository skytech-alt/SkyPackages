# sky-caesar

## Установка

**Python:**
```bash
pip install sky-caesar
```

**npm:**
```bash
npm install @skypackages/caesar
```

**SkyForge:**
```bash
SkyForge install skyforge-caesar
```

## Python API

### `encode(text, shift)`

### `decode(text, shift)`

### Пример использования

```python
from sky_caesar import encode

encode("example", None)
```

## TypeScript / JavaScript API

### `encode(text, shift)`

### `decode(text, shift)`

### Пример использования

```typescript
import { encode } from "@skypackages/caesar";

encode("example", None);
```

## SkyForge

Шифр Цезаря для латиницы.

```skyforge
пусть lib = подтянуть "skyforge-caesar"
лог(lib.encode())
```
