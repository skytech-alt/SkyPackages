# sky-retry-bundle

## Установка

**Python:**
```bash
pip install sky-retry-bundle
```

**npm:**
```bash
npm install @skypackages/retry-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-retry-bundle
```

## SkyForge

Повторные попытки с экспоненциальной задержкой (backoff) для SkyForge.

```skyforge
пусть lib = подтянуть "skyforge-retry-bundle"
```
