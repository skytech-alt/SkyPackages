# sky-words-bundle

## Установка

**Python:**
```bash
pip install sky-words-bundle
```

**npm:**
```bash
npm install @skypackages/words-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-words-bundle
```

## SkyForge

Подсчет слов и оценка времени чтения текста.

```skyforge
пусть lib = подтянуть "skyforge-words-bundle"
```
