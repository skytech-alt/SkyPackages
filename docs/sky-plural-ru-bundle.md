# sky-plural-ru-bundle

## Установка

**Python:**
```bash
pip install sky-plural-ru-bundle
```

**npm:**
```bash
npm install @skypackages/plural-ru-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-plural-ru-bundle
```

## SkyForge

Склонение русских существительных по числам.

```skyforge
пусть lib = подтянуть "skyforge-plural-ru-bundle"
```
