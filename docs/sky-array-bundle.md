# sky-array-bundle

## Установка

**Python:**
```bash
pip install sky-array-bundle
```

**npm:**
```bash
npm install @skypackages/array-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-array-bundle
```

## SkyForge

Утилиты для массивов: chunk, unique, flatten.

```skyforge
пусть lib = подтянуть "skyforge-array-bundle"
```
