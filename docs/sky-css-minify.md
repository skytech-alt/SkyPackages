# sky-css-minify

## Установка

**Python:**
```bash
pip install sky-css-minify
```

**npm:**
```bash
npm install @skypackages/css-minify
```

**SkyForge:**
```bash
SkyForge install skyforge-css-minify
```

## Python API

### `minify(css)`

### Пример использования

```python
from sky_css_minify import minify

minify(None)
```

## TypeScript / JavaScript API

### `minify(css)`

### Пример использования

```typescript
import { minify } from "@skypackages/css-minify";

minify(None);
```

## SkyForge

Минификация CSS.

```skyforge
пусть lib = подтянуть "skyforge-css-minify"
лог(lib.minify())
```
