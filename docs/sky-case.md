# sky-case

Конвертация регистров строк: camelCase, snake_case, kebab-case, PascalCase.

## Установка

```bash
pip install sky-case
npm install @skypackages/case
SkyForge install sky-case
```

## API Reference

### Python

#### `def _split_words(text)`
*Документация отсутствует.*

#### `def to_camel(text)`
hello world -> helloWorld

#### `def to_pascal(text)`
hello world -> HelloWorld

#### `def to_snake(text)`
hello world -> hello_world

#### `def to_kebab(text)`
hello world -> hello-world

#### `def to_constant(text)`
hello world -> HELLO_WORLD
