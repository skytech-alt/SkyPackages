# sky-uuid-validate

## Установка

**Python:**
```bash
pip install sky-uuid-validate
```

**npm:**
```bash
npm install @skypackages/uuid-validate
```

**SkyForge:**
```bash
SkyForge install skyforge-uuid-validate
```

## Python API

### `is_valid(uuid_str)`

### Пример использования

```python
from sky_uuid_validate import is_valid

is_valid("example")
```

## TypeScript / JavaScript API

### `isValid(uuidStr)`

### Пример использования

```typescript
import { isValid } from "@skypackages/uuid-validate";

isValid("example");
```

## SkyForge

Проверка строки на формат UUID.

```skyforge
пусть lib = подтянуть "skyforge-uuid-validate"
лог(lib.is_valid())
```
