# sky-factorial

## Установка

**Python:**
```bash
pip install sky-factorial
```

**npm:**
```bash
npm install @skypackages/factorial
```

**SkyForge:**
```bash
SkyForge install skyforge-factorial
```

## Python API

### `factorial(n)`

### Пример использования

```python
from sky_factorial import factorial

factorial(42)
```

## TypeScript / JavaScript API

### `factorial(n)`

### Пример использования

```typescript
import { factorial } from "@skypackages/factorial";

factorial(42);
```

## SkyForge

Вычисление факториала.

```skyforge
пусть lib = подтянуть "skyforge-factorial"
лог(lib.factorial())
```
