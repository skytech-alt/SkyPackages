# sky-ascii

## Установка

**Python:**
```bash
pip install sky-ascii
```

**npm:**
```bash
npm install @skypackages/ascii
```

**SkyForge:**
```bash
SkyForge install skyforge-ascii
```

## Python API

### `to_code(char)`

### `to_char(code)`

### Пример использования

```python
from sky_ascii import to_code

to_code(None)
```

## TypeScript / JavaScript API

### `toCode(char)`

### `toChar(code)`

### Пример использования

```typescript
import { toCode } from "@skypackages/ascii";

toCode(None);
```

## SkyForge

Конвертация символа в ASCII-код и обратно.

```skyforge
пусть lib = подтянуть "skyforge-ascii"
лог(lib.to_code())
```
