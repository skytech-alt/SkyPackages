# sky-unicode

## Установка

**Python:**
```bash
pip install sky-unicode
```

**npm:**
```bash
npm install @skypackages/unicode
```

**SkyForge:**
```bash
SkyForge install skyforge-unicode
```

## Python API

### `to_code(char)`

### `to_char(code)`

### Пример использования

```python
from sky_unicode import to_code

to_code(None)
```

## TypeScript / JavaScript API

### `toCode(char)`

### `toChar(code)`

### Пример использования

```typescript
import { toCode } from "@skypackages/unicode";

toCode(None);
```

## SkyForge

Код символа в Unicode и обратно.

```skyforge
пусть lib = подтянуть "skyforge-unicode"
лог(lib.to_code())
```
