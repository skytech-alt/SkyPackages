# sky-bank-card-bundle

## Установка

**Python:**
```bash
pip install sky-bank-card-bundle
```

**npm:**
```bash
npm install @skypackages/bank-card-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-bank-card-bundle
```
