# sky-id-bundle

## Установка

**Python:**
```bash
pip install sky-id-bundle
```

**npm:**
```bash
npm install @skypackages/id-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-id-bundle
```

## SkyForge

Генерация идентификаторов (UUID, NanoID).

```skyforge
пусть lib = подтянуть "skyforge-id-bundle"
```
