# sky-duration-bundle

## Установка

**Python:**
```bash
pip install sky-duration-bundle
```

**npm:**
```bash
npm install @skypackages/duration-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-duration-bundle
```

## SkyForge

Парсинг и форматирование времени и размеров для SkyForge.

```skyforge
пусть lib = подтянуть "skyforge-duration-bundle"
```
