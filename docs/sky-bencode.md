# sky-bencode

## Установка

**Python:**
```bash
pip install sky-bencode
```

**npm:**
```bash
npm install @skypackages/bencode
```

**SkyForge:**
```bash
SkyForge install skyforge-bencode
```

## Python API

### `encode(obj)`

### `decode(text)`

### Пример использования

```python
from sky_bencode import encode

encode(None)
```

## TypeScript / JavaScript API

### `encode(obj)`

### `decode(text)`

### Пример использования

```typescript
import { encode } from "@skypackages/bencode";

encode(None);
```
