# sky-env-bundle

## Установка

**Python:**
```bash
pip install sky-env-bundle
```

**npm:**
```bash
npm install @skypackages/env-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-env-bundle
```

## SkyForge

Типизированный доступ к переменным окружения.

```skyforge
пусть lib = подтянуть "skyforge-env-bundle"
```
