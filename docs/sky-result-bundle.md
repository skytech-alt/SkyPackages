# sky-result-bundle

## Установка

**Python:**
```bash
pip install sky-result-bundle
```

**npm:**
```bash
npm install @skypackages/result-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-result-bundle
```

## SkyForge

Result и Option для безопасной обработки ошибок на SkyForge.

```skyforge
пусть lib = подтянуть "skyforge-result-bundle"
```
