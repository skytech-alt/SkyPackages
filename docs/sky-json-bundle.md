# sky-json-bundle

## Установка

**Python:**
```bash
pip install sky-json-bundle
```

**npm:**
```bash
npm install @skypackages/json-bundle
```

**SkyForge:**
```bash
SkyForge install skyforge-json-bundle
```

## SkyForge

Проверка валидности JSON.

```skyforge
пусть lib = подтянуть "skyforge-json-bundle"
```
