# sky-leet

## Установка

**Python:**
```bash
pip install sky-leet
```

**npm:**
```bash
npm install @skypackages/leet
```

**SkyForge:**
```bash
SkyForge install skyforge-leet
```

## Python API

### `to_leet(text)`

### `from_leet(text)`

### Пример использования

```python
from sky_leet import to_leet

to_leet("example")
```

## TypeScript / JavaScript API

### `toLeet(text)`

### `fromLeet(text)`

### Пример использования

```typescript
import { toLeet } from "@skypackages/leet";

toLeet("example");
```

## SkyForge

Leetspeak конвертер.

```skyforge
пусть lib = подтянуть "skyforge-leet"
лог(lib.to_leet())
```
