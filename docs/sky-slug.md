# sky-slug

Генерация URL-слагов из текста с поддержкой транслитерации (кириллица).

## Установка

```bash
pip install sky-slug
npm install @skypackages/slug
SkyForge install sky-slug
```

## API Reference

### Python

#### `def slugify(text, max_length)`
Превращает текст в URL-слаг.

Пример: 'Привет, мир!' -> 'privet-mir'

### TypeScript / JavaScript

#### `slugify(text, maxLength)`
*Документация отсутствует.*

### SkyForge

#### `функция slugify(текст)`
Функция реализована на SkyForge.
