# Политика безопасности (Security Policy)

## Поддерживаемые версии

Мы стремимся поддерживать безопасность всех актуальных версий пакетов SkyPackages. 
Так как проект развивается, обновления безопасности выпускаются для последних мажорных версий пакетов.

| Версия | Поддерживается |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Сообщение об уязвимости

Пожалуйста, **не сообщайте об уязвимостях в публичных Issues**. 

Используйте встроенный механизм GitHub: перейдите во вкладку **Security** в верхней части этого репозитория и нажмите **Report a vulnerability** (Приватные отчеты).

### Что включить в отчет:
* Экосистема (Python, npm или SkyForge).
* Название пакета и его версия.
* Подробное описание уязвимости и шаги для её воспроизведения (PoC).
* Возможное влияние на пользователей.

### Чего ожидать:
* Мы подтвердим получение отчета в течение **48 часов**.
* Мы будем держать вас в курсе процесса исправления.
* После выпуска патча мы публично поблагодарим вас за обнаружение (если вы не хотите остаться анонимным).
